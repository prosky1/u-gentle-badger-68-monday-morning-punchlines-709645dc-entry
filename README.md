## The joke

> Monday is the only day the snooze button files for overtime.

## How it works

`main.ts` (Node 22+) validates the joke — 1–200 characters, a single line,
plain ASCII, about Monday mornings — and writes it to `/output/entry.txt`,
then reads it back to verify the output is byte-identical.

```sh
node main.ts
```
